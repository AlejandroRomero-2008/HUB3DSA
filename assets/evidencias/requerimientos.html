Gym Big Strong · requerimientos funcionales y no funcionales

Documento real del sistema de gimnasio: registro de clientes, pagos, asistencia, roles y requisitos de respuesta y seguridad.

Extracto del archivo original

Requerimientos Funcionales
Los requerimientos funcionales describen lo que el sistema debe hacer.
Código
Requerimiento
RF-01
El sistema deberá permitir el inicio de sesión mediante usuario y contraseña.
RF-02
El sistema deberá registrar nuevos clientes con sus datos personales.
RF-03
El sistema deberá modificar la información de los clientes registrados.
RF-04
El sistema deberá eliminar registros de clientes cuando sea necesario.
RF-05
El sistema deberá registrar las membresías de los clientes.
RF-06
El sistema deberá registrar y almacenar los pagos de mensualidades.
RF-07
El sistema deberá registrar la asistencia diaria de los clientes.
RF-08
El sistema deberá consultar el historial de asistencias de cada cliente.
RF-09
El sistema deberá administrar rutinas de entrenamiento asignadas a los clientes.
RF-10
El sistema deberá permitir a los coaches consultar y actualizar rutinas.
RF-11
El sistema deberá generar reportes de clientes activos y vencidos.
RF-12
El sistema deberá generar reportes de asistencia.
RF-13
El sistema deberá realizar respaldos automáticos de la base de datos.
RF-14
El sistema deberá restaurar la información desde una copia de seguridad cuando sea necesario.
RF-15
El sistema deberá administrar los roles de Administrador, Recepcionista y Coach.

Requerimientos No Funcionales
Los requerimientos no funcionales describen cómo debe funcionar el sistema.
Código
Requerimiento
RNF-01
El tiempo de respuesta del inicio de sesión no deberá superar los 2 segundos.
RNF-02
El registro de clientes deberá completarse en un máximo de 3 segundos.
RNF-03
La consulta de asistencias deberá mostrarse en un máximo de 3 segundos.
RNF-04
El registro de pagos deberá almacenarse en un máximo de 4 segundos.
RNF-06
El sistema deberá contar con autenticación mediante usuario y contraseña.
RNF-07
El sistema deberá restringir el acceso según el rol del usuario.
RNF-08
El sistema deberá proteger la información almacenada contra accesos no autorizados.
RNF-09
El sistema deberá realizar respaldos automáticos semanales.
RNF-11
El sistema deberá ser compatible con las tres computadoras del gimnasio.
RNF-12
La interfaz deberá ser fácil de usar para personal con conocimientos básicos de informática.
RNF-13
El sistema deberá mantener la integridad de la información registrada.
RNF-14
El sistema deberá permitir actualizaciones mensuales sin afectar los datos existentes.
RNF-16
El sistema deberá garantizar la confidencialidad de los datos de clientes y pagos.
