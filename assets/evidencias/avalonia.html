Avalonia · eventos y municipios dependientes

Extracto real del formulario: inicialización, eventos de controles y selección de municipios según el departamento. El archivo también contiene validaciones adicionales.

Extracto del archivo original

    public MainWindow()
    {
        InitializeComponent();

        CargarDepartamentos();

        // Eventos
        txtNombre.TextChanged += TxtNombre_TextChanged;
        dpNacimiento.PropertyChanged += DpNacimiento_PropertyChanged;
        cmbDepartamento.SelectionChanged += CmbDepartamento_SelectionChanged;
    }

    // =========================
    // Cargar departamentos
    // =========================

    private void CargarDepartamentos()
    {
        cmbDepartamento.ItemsSource = departamentos.Keys.ToList();
    }

    // =========================
    // Departamento -> Municipio
    // =========================

    private void CmbDepartamento_SelectionChanged(object? sender, SelectionChangedEventArgs e)
    {
        if (cmbDepartamento.SelectedItem is string departamento)
        {
            cmbMunicipio.ItemsSource = departamentos[departamento];
        }
    }
