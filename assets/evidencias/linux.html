MANUAL DE COMANDOS PARA PRINCIPIANTES
1. Comando ls
El comando ls se utiliza para listar (mostrar) los archivos y carpetas que hay dentro del directorio en el que te encuentras. Es uno de los comandos más usados porque te permite ver qué tienes disponible.
Ejemplos:
lsMuestra los archivos y carpetas de la ubicación actual.
ls -lMuestra una lista detallada con permisos, tamaño, fecha y propietario.
ls nombre_carpetaMuestra el contenido de una carpeta específica.

2. Comando cd
El comando cd sirve para cambiar de directorio, es decir, moverte entre carpetas dentro del sistema.
Ejemplos:
cd DocumentosEntra a la carpeta Documentos.
cd ..Regresa a la carpeta anterior.
cd /Te lleva a la raíz del sistema.

3. Comando pwd
El comando pwd muestra la ruta completa del directorio en el que estás actualmente.
Ejemplos:
pwdMuestra algo como /home/usuario, indicando tu ubicación.

4. Comando cat
El comando cat se utiliza para ver el contenido de archivos de texto directamente en la terminal.
Ejemplos:
cat archivo.txtMuestra todo el contenido del archivo.

5. Comando mkdir
El comando mkdir permite crear nuevas carpetas o directorios.
Ejemplos:
mkdir proyectosCrea una carpeta llamada “proyectos”.
